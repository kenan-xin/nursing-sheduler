## 1. Summary

1. In this lane, v1 `dev` split `core/requirements.txt` into a runtime set and `requirements-optional.txt` (`3e1a59c`). It also raised `requires-python` to `>=3.12` (`14258d2`) and added the Python AI service dependencies (`e2b`, `psycopg`, `Pillow`, `defusedxml`, `pypdf`, `pypdfium2`).
2. v1 `dev` added about 110 new test files. Most of them are for the Python AI assistant (30 `test_ai_*.py` files, `tests/ai_eval/**`, 109 eval case JSON files). The others cover Sentry, suspicious requests, usage telemetry, retry, a performance benchmark and a ground-truth score replay.
3. The genie merge `1b6f7e5` removes Sentry, the anonymizer, the suspicion tracker and the PuLP CBC/cuOpt paths again. For these items, v2 is already the same as genie. Genie keeps PuLP (`pulp==3.3.2`), HiGHS, SCIP and the multi-solver tests, and v2 does not have them.
4. The v1 Docker stack grew to 9 services (Postgres, pgAdmin, Redis, RedisInsight, api, ai, NGINX, cloudflared, usage-reporter), plus a diagnostic profile. The recent network commits isolate 5 networks. They pinned subnets and then removed the fixed addresses (`8da5bc0`, `c51118b`, `e129250`, `81ed5f9`). v2 has its own 3-network private topology, which already reaches the same end state.
5. Headline risk 1: v2 CI (`.github/workflows/ci.yml`) never runs core `pytest` or `ruff` (verified by grep). v1 runs 7 core workflows. `docker/README.md:390` says that the backend gate runs on "host / CI", but the CI part is false.
6. Headline risk 2: the v2 production image installs `pytest`, `pytest-cov`, `ruff` and `fakeredis`, because v2 `core/requirements.txt` still holds them. The v1 split removes this problem.
7. Headline risk 3: v1 leaves `ruamel.yaml` and `pydantic` unpinned. v2 pins them (`0.19.1`, `2.13.4`) because canonical YAML bytes depend on them. A verbatim adoption of the v1 requirements files will drop these pins.
8. Headline risk 4: v1 `dev` and genie have 9 Ruff violations under Ruff 0.15.x defaults. The genie merge message `1b6f7e5` confirms this ("only the 9 violations dev also has"). v2 pins `ruff==0.15.22`, so ported files can fail the v2 gate.
9. Python version is the same on both sides: `>=3.12`, CI 3.12, images `python:3.12-slim`. `ortools==9.15.6755` is identical.
